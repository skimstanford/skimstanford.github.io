ALEXANDER P. KIM — WEBSITE

HOW TO EDIT

The website is intentionally very simple. Each page is a plain HTML file.
Look for the comments: EDIT THIS TEXT. Everything between those comments
is intended for you to edit. The comments themselves do not appear on the site.

SHARED HEADER

The header is now stored in header.html. Every page loads this file, so you
only need to edit header.html when you want to change the header, email,
language selection, or navigation.

The footer is stored in footer.html and is also shared across every page.
